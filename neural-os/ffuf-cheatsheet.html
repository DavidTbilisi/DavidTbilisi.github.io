FFUF Cheat Sheet

Fuzz Faster U Fool — Web Fuzzer Quick Reference

⚙️ Install & Run
# Go install (latest) go install github.com/ffuf/ffuf/v2@latest # apt sudo apt install ffuf # verify ffuf -V # basic syntax ffuf -u https://target.com/FUZZ \ -w /path/to/wordlist.txt
The FUZZ keyword marks the injection point. Custom keyword: -w list.txt:MYWORD
📁 Directory & File Fuzzing
# directories ffuf -u https://target.com/FUZZ \ -w ~/wordlists/raft-medium-directories.txt # files with extension ffuf -u https://target.com/FUZZ.php \ -w ~/wordlists/raft-medium-files.txt # multiple extensions at once ffuf -u https://target.com/FUZZ \ -w wordlist.txt \ -e .php,.html,.txt,.bak,.js # recursive ffuf -u https://target.com/FUZZ \ -w wordlist.txt \ -recursion -recursion-depth 3
🌐 Subdomain & VHost Fuzzing
# subdomain (DNS) ffuf -u https://FUZZ.target.com \ -w ~/wordlists/subdomains.txt # virtual host (Host header) ffuf -u https://target.com \ -H "Host: FUZZ.target.com" \ -w ~/wordlists/subdomains.txt \ -fs 1234 # filter default response size
For VHost: always filter by size (-fs) or words (-fw) to remove the default response.
🔎 GET Parameter Fuzzing
# fuzz parameter name ffuf -u https://target.com/page?FUZZ=value \ -w ~/wordlists/params.txt # fuzz parameter value ffuf -u https://target.com/page?id=FUZZ \ -w ~/wordlists/numbers.txt # fuzz both name and value ffuf -u https://target.com/?W1=W2 \ -w params.txt:W1 \ -w values.txt:W2 \ -mode clusterbomb
📤 POST Data Fuzzing
# POST body fuzz ffuf -u https://target.com/login \ -X POST \ -d "username=admin&password=FUZZ" \ -H "Content-Type: application/x-www-form-urlencoded" \ -w ~/wordlists/passwords.txt # JSON POST body ffuf -u https://target.com/api/login \ -X POST \ -d '{"username":"admin","password":"FUZZ"}' \ -H "Content-Type: application/json" \ -w passwords.txt # fuzz POST parameter name ffuf -u https://target.com/form \ -X POST \ -d "FUZZ=value" \ -w params.txt
📨 Header Fuzzing
# fuzz header value ffuf -u https://target.com/ \ -H "X-Forwarded-For: FUZZ" \ -w ips.txt # fuzz header name ffuf -u https://target.com/ \ -H "FUZZ: ../../../etc/passwd" \ -w headers.txt # Authorization header ffuf -u https://target.com/api/FUZZ \ -H "Authorization: Bearer TOKEN" \ -w endpoints.txt:FUZZ \ -w tokens.txt:TOKEN # cookie fuzzing ffuf -u https://target.com/admin \ -b "session=FUZZ" \ -w tokens.txt

⚠ Default is 40 threads. Lower with -t 10 to avoid detection or crashing the target.
🎲 Multi-Wordlist Modes
sniper (default)one wordlist, one FUZZ
pitchforkN wordlists in sync (zip)
clusterbombN wordlists × all combos
# pitchfork — user:pass pairs (same index) ffuf -u https://target.com/login \ -X POST \ -d "user=W1&pass=W2" \ -w users.txt:W1 -w passes.txt:W2 \ -mode pitchfork # clusterbomb — every user × every pass ffuf -u https://target.com/login \ -X POST \ -d "user=W1&pass=W2" \ -w users.txt:W1 -w passes.txt:W2 \ -mode clusterbomb
🔐 Authentication
# Basic Auth ffuf -u https://target.com/FUZZ \ -w wordlist.txt \ -H "Authorization: Basic YWRtaW46cGFzcw==" # Bearer token ffuf -u https://target.com/api/FUZZ \ -w endpoints.txt \ -H "Authorization: Bearer <token>" # Cookie-based session ffuf -u https://target.com/admin/FUZZ \ -w wordlist.txt \ -b "PHPSESSID=abc123; auth=1" # replay from Burp request file ffuf -request req.txt \ -request-proto https \ -w wordlist.txt
-request loads a raw HTTP request file — paste from Burp Suite, replace the injection point with FUZZ.

🧪 Common Attack Scenarios
# ── LFI (Local File Inclusion) ─────────────────────────────── ffuf -u "https://target.com/page?file=FUZZ" \ -w LFI-Jhaddix.txt \ -mr "root:" # match /etc/passwd content # ── IDOR (Insecure Direct Object Reference) ────────────────── ffuf -u "https://target.com/api/user/FUZZ/profile" \ -w <(seq 1 1000) # bash process substitution \ -b "session=victim_token" \ -mc 200 # ── API version fuzzing ─────────────────────────────────────── ffuf -u "https://target.com/FUZZ/users" \ -w <(echo -e "v1\nv2\nv3\napi\napi/v1\napi/v2") # ── Backup file discovery ───────────────────────────────────── ffuf -u "https://target.com/FUZZ" \ -w wordlist.txt \ -e .bak,.old,.orig,.backup,~,.swp \ -mc 200 # ── Username enumeration (different response size) ──────────── ffuf -u "https://target.com/login" \ -X POST \ -d "username=FUZZ&password=wrongpass" \ -H "Content-Type: application/x-www-form-urlencoded" \ -w usernames.txt \ -fs 3271 # baseline size for "wrong username" response # ── Through Burp proxy (intercept & analyse) ───────────────── ffuf -u "https://target.com/FUZZ" \ -w wordlist.txt \ -x http://127.0.0.1:8080 \ -k
