💾 შენახვის ციკლი

🌿 ტოტები (Branches)
სიის ნახვაgit branch
ყველა (+ remote)git branch -a
ახ. ტოტიgit branch <სახელი>
ახ. + გადასვლაgit switch -c <სახელი>
გადასვლაgit switch <სახელი>
წინა ტოტიgit switch -
გადარქმევაgit branch -m ძველი ახალი
წაშლა (შერწყ.)git branch -d <სახელი>
წაშლა (ძალით)git branch -D <სახელი>

ტოტ. ბოლო კომ.git branch -v
🔀 შერწყმა (Merge)
შერწყმაgit merge <ტოტი>
მხოლოდ ffgit merge --ff-only <ტოტი>
ყოველ. merge-commitgit merge --no-ff <ტოტი>
შეკუმშვით (squash)git merge --squash <ტოტი>
merge-ის გაუქმებაgit merge --abort
კონფლიქტებიgit status
კონფ. მონიშვნაgit add <ფაილი>
merge დასრულებაgit commit
კონფლიქტის ნიშნები: <<<<< HEAD / ======= / >>>>> <ტოტი>. ამოშალე ნიშნები, შეინახე სასურველი კოდი.
🌐 დისტანციური (Remote)
სიის ნახვაgit remote -v
დამატებაgit remote add origin <url>
URL შეცვლაgit remote set-url origin <url>
წაშლაgit remote remove origin
მოტანა (fetch)git fetch origin
ყველა fetchgit fetch --all
pull (fetch+merge)git pull
pull + rebasegit pull --rebase
pushgit push origin <ტოტი>
push + trackinggit push -u origin <ტოტი>
ყველა ტოტიgit push --all
⚠ git push --force — საშიშია. გამოიყენე --force-with-lease.
↩️ გაუქმება (Undo)
ცვლ. გაუქმებაgit restore <ფაილი>
unstagegit restore --staged <ფაილი>
reset --softgit reset --soft HEAD~1
reset --mixedgit reset HEAD~1
reset --hardgit reset --hard HEAD~1
revert (უსაფრთხო)git revert <hash>
revert — no commitgit revert -n <hash>
merge-ის revertgit revert -m 1 <hash>
reset — ამოშლის კომიტს ლოკალურად.
revert — ქმნის ახალ კომიტს, რომელიც უქმყოფს ცვლილებებს. გამოიყენე push-ის შემდეგ.
✏️ ისტ. გადაწერა (Rebase)
rebase on maingit rebase main
ინტ. rebasegit rebase -i HEAD~3
rebase გაუქმებაgit rebase --abort
კონფლ. შემდ. გაგრ.git rebase --continue
ერთი კომ. გადატ.git cherry-pick <hash>
cherry-pick — no commitgit cherry-pick -n <hash>
amend (ბოლო კომ.)git commit --amend
# ინტ. rebase ოპციები: pick abc1 კომიტი # დატოვე reword abc2 კომიტი # შეტყ. შეცვლა squash abc3 კომიტი # წინაში ჩართე fixup abc4 კომიტი # squash, შეტ. გარეშე drop abc5 კომიტი # წაშალე
⚠ rebase-ი ცვლის hash-ებს. არ გამოიყენო push-ის შემდეგ.

გამოყენება + წაშლაgit stash pop

ახ. ტოტადgit stash branch <სახ.> stash@{0}
