The Color Cylinder · drag to orbit

Every color is one point in this 3D solid. Three moves reach any of them.

⟳ Hue — spin the dial ↕ Value — slide up/down ⊙ Saturation — pull from core

The Harmony Wheel · geometry = palette

Pick one base hue, then a shape. Related colors become angle calculations.

Base hue 20°

⟳ Hue — 0°–360°

The spin move. Identity of the color family: red → yellow → green → blue → violet → back. On the wheel it is the only thing the harmony shapes touch.

↕ Value — 0%→100%

The slide move (a dimmer switch). Black at the floor, white at the cap. A flat palette = everything stuck on one ring; add a dark anchor + light highlight.

⊙ Saturation — core→rim

The pull move. Gray axis in the center, pure hue at the rim. Muddy → pull outward; garish → push in or lift value.
